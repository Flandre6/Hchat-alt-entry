# 莫奈引擎模块生成器

入口：Hchat 设置 -> 实用 -> 美化 -> 莫奈引擎模块生成器。

## 前置条件

- Android 12 或更高版本。
- Magisk、KernelSU、APatch 或兼容的 Root 模块管理器。
- 当前微信 base APK 和资源 split APK 可由微信进程正常读取。

生成器只在用户点击“生成模块”后运行，不会在微信启动时扫描 APK。它读取当前安装的微信资源，使用结构规则和必要的 DexKit 证据解析混淆资源，生成并签名多套 RRO Overlay APK，再打包为 Root 管理器可安装的 ZIP。

## 生成选项

- 气泡样式：现代圆角、经典微信、Pro 圆角。
- 多场景圆角：输入栏、引用区域和支付键盘等界面。
- 底栏样式：纯色莫奈或半透明莫奈。
- Android 用户范围：仅当前用户或全部用户。

设置通过 Hchat 配置存储即时保存。输出使用 Android 系统“创建文件”选择器，不需要公共存储写权限。

## 安装与更新

1. 选择生成选项并点击“生成模块”。
2. 在系统文件选择器中确定 ZIP 保存位置。
3. 等待资源图构建、语义解析、Overlay 构建、签名和打包完成。
4. 使用 Root 管理器安装生成的 ZIP，并按管理器提示重启。
5. KernelSU/APatch 用户如果发现 Overlay 不生效，需要检查微信的“卸载模块”选项。

生成结果只针对生成时安装的微信版本。微信升级、降级或资源 split 变化后，应重新生成并重新验证。生成成功只表示 ZIP 已写出，不代表目标设备已经完成安装或界面效果验证。

## 实现与来源

Hchat 复用共享 DexKitBridge，并通过 `DexInstallScheduler.runDexKitTask(...)` 串行执行 DEX 证据分析；资源解析和文件生成在独立后台线程运行。临时文件位于微信缓存目录的 `Hchat/monet_generator/` 下，任务结束后清理。

核心资源图、语义匹配、Overlay 生成、签名和 Root 模块打包代码适配自 `Flandre6/WeKit` 提交 `bdc7f18033d87a2f6307d2caedfdc6502986a401`，遵循 GPL-3.0。许可证副本见 `docs/third_party/monet-engine-module-generator-GPL-3.0.txt`。

当前仓库没有随附微信 APK 样本或真机验证结果，因此尚未确认微信 8.0.49、8.0.58、8.0.66、8.0.68、8.0.72、8.0.74、8.0.76、8.0.77 的生成与安装效果。
