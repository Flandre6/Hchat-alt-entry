# alt-entry 功能同步说明

本分支同步了 `alt-entry-feature` 中已验证的功能实现：

- 安全消息与反安全消息：分别使用独立配置，安全消息默认开启，反安全消息默认关闭；支持文字、链接、卡片、图片、视频和表情包的消息标记处理。表情消息额外覆盖 8.0.76/3140 与 8.0.77/3160 的 MsgSource 提供者、`sendemoji` 请求分发链路和自发表情安全检查兜底，避免上传或本地回显阶段重新生成 MsgSource 后丢失安全限制；该链路使用安全消息总开关并作用于所有会话。
- 上传透明头像：仅在头像上传/裁剪流程保留 PNG Alpha 通道，默认关闭。
- 会话时间样式：保留微信原样、自定义、每条消息显示和隐藏模式；定位按微信运行时缓存。
- 左滑引用/右滑复读：使用 `ChattingRecyclerView` 候选、绑定兜底、`ACTION_DOWN` 命中缓存和单一触摸入口优先策略；移动事件不重复递归扫描，并在媒体滑动期间避免行回收闪烁。
- 关于页推送更新：从 `Flandre6/Hchat-alt-entry` 最新 Release 读取说明，优先打开 `alt-entry` APK；微信主进程启动后每 12 小时后台检查一次，按 Release tag 去重系统通知。

这些功能均通过 `FeatureRegistry` 注册，并从 Miuix 设置页的聊天/美化分组进入。微信混淆类定位仍依赖目标版本 DexKit 缓存；未在本机完成微信 8.0.77 真机验证时，不应将静态编译结果视为设备行为验证。
