# alt-entry 功能同步说明

本分支同步了 `alt-entry-feature` 中已验证的功能实现：

- 安全消息与反安全消息：分别使用独立配置，安全消息默认开启，反安全消息默认关闭；支持文字、链接、卡片、图片、视频和表情包的消息标记处理。表情消息额外覆盖 8.0.76/3140、8.0.77/3160 与 8.0.78/3180 的 MsgSource 提供者、`sendemoji` 请求分发链路和自发表情安全检查兜底，避免上传或本地回显阶段重新生成 MsgSource 后丢失安全限制；该链路使用安全消息总开关并作用于所有会话。
- 上传透明头像：仅在头像上传/裁剪流程保留 PNG Alpha 通道，默认关闭。
- 会话时间样式：保留微信原样、自定义、每条消息显示和隐藏模式；定位按微信运行时缓存。
- 左滑引用/右滑复读：使用 `ChattingRecyclerView` 候选、绑定兜底、`ACTION_DOWN` 命中缓存和单一触摸入口优先策略；移动事件不重复递归扫描，并在媒体滑动期间避免行回收闪烁。
- 关于页推送更新：从 `Flandre6/Hchat-alt-entry` 最新 Release 读取说明，优先打开 `alt-entry` APK；微信主进程启动后每 12 小时后台检查一次，按 Release tag 去重系统通知。
- 聊天工具栏：入口位于 `实用 → 增强 → 聊天工具栏`，默认关闭；在输入框上方动态镜像当前聊天微信 `+` 面板中的相册、拍摄、通话、位置、红包、转账和文件等工具，支持图文、仅图标、仅文字、逐项启停、顺序调整及快捷回复。工具点击目标按每个 `AppPanel` 隔离，设置保存后实时刷新；DexKit 定位结果按微信运行时缓存并通过统一调度器有限补装。功能依据 `Flandre6/WeKit` 提交 `bdc7f18033d87a2f6307d2caedfdc6502986a401`（GPL-3.0）重新实现，未迁移 WeAgent 入口。当前没有逐功能真机验证，微信 8.0.49、8.0.58、8.0.66、8.0.68、8.0.72、8.0.74、8.0.76、8.0.77、8.0.78 均需以设备日志复核。
- 首页侧边栏：入口位于 `实用 → 美化 → 首页侧边栏`，默认关闭；在微信首页左缘右滑打开 OKK 风格快捷抽屉，可配置签名和最多三个快捷入口。仅挂载到首页 `LauncherUI`，不影响聊天页面；微信内部类定位失败时会记录 Hchat 日志并安全跳过。

这些功能均通过 `FeatureRegistry` 注册，并从 Miuix 设置页的聊天/美化分组进入。微信混淆类定位仍依赖目标版本 DexKit 缓存；8.0.78 APK 的关键锚点已做离线字符串对比，但仍需在微信 8.0.78 真机验证时以 LSPosed 日志确认各功能入口。
