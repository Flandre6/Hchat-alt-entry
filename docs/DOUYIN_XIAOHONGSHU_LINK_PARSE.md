# 抖音 / 小红书链接解析

功能位于“设置 → 聊天 → 链接解析”，默认关闭，支持公开的抖音、小红书视频与图集链接。

- 自己发送的有效作品链接可在任意会话解析；其他成员的链接只在单独选择的聊天白名单中解析。可选开启“群聊仅 @我触发”，只限制白名单群聊中的其他成员，不限制自己发送或私聊。
- 聊天白名单保存在链接解析自己的配置中，与 QQ 点歌白名单分开。
- 视频与图集发送复用微信媒体 API。抖音图集只读取作品原图字段，不使用带平台水印的下载字段。
- 链接按平台主机名和作品路径校验；解析请求不带 Cookie，重定向、读取时限、文件大小和缓存都有上限。重复消息由消息身份和处理状态去重；自己发送的消息只接受已发送状态。
- 当前只支持抖音和小红书，不包含快手解析。

实现同时监听微信消息事件和消息表变化，并在发送队列执行前再次检查开关、白名单及群聊 @ 限制。详情见 `app/src/main/java/h/Hchat/hooks/items/linkparse/`。

自己发送的消息写入观察沿用 WeiPlus 已完成的 SQLite 锚点，按微信运行时身份缓存定位结果，并使用项目共享 DexKit 调度器；缓存失效或定位失败时关闭该补偿入口，不拦截微信原始消息写入。视频优先复用现有媒体 API，新版发送链路回退同样按运行时缓存定位结果。
